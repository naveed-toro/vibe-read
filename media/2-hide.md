## Stay in the code.

Click **Hide** at the bottom — or press **`Alt+M`**.

**Before**
```js
// Lock the button the moment it is tapped.
button.disabled = true;
```
**After**
```js
// Lock the button the moment it is tapped.
⋯
```

Nothing is edited. Click **Show** and it all comes back.
Select a few lines first to hide only those.
