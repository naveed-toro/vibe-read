# The recordings

Drop the finished `.gif` files in this folder, commit, push. GitHub then serves
them at a fixed address and both the repo page and the marketplace page show
them — the marketplace cannot read a relative path, which is why the links
below are absolute.

Paste-ready. Nothing to edit but the file names.

```markdown
![Alt+M opens the reading page](https://raw.githubusercontent.com/naveed-toro/vibe-read/main/media/gifs/read.gif)

![Alt+X hides the code where it stands](https://raw.githubusercontent.com/naveed-toro/vibe-read/main/media/gifs/hide.gif)
```

## read.gif — the one that decides whether anybody installs this

Nobody reads a marketplace page. They scroll for two seconds, watch whatever
moves, and decide. With no download count yet, this picture carries the whole
argument on its own.

1. Open a real file with real comments — not the sample. Something with long
   stretches of code between the explanations, so the change is dramatic.
2. Hold still for one second. Let the eye see an ordinary, crowded file.
3. Press `Alt+M`. The reading page takes the screen.
4. Hold **four seconds**. This pause *is* the recording: it is the moment
   somebody realises they are reading English instead of code. Do not cut it.
5. Scroll once, slowly, so the folds go by. Stop.

About 8 seconds, looping.

## hide.gif — the same idea, in place

1. Same file, code showing.
2. Press `Alt+X`. The code goes; the reasoning stays where it was.
3. Hold 3 seconds.
4. Press `Alt+X` again — everything is back, nothing was edited. Stop.

About 6 seconds.

## select.gif — small, and deliberately so

Watching the first two, a reader thinks: that is a blunt instrument, I would
want some of the code. This answers that. The doubt forms after the pitch, not
before it, so this one must not compete with the first for attention.

1. Code already hidden.
2. Frame **eight or ten lines only**, not the whole editor. That is what keeps
   the file small.
3. Drag-select two or three lines. The selection must be visible.
4. Press `Alt+X`. Only that code comes back. Hold 2 seconds. Stop.

About 4 seconds.

## save.gif — optional

1. On the reading page, press **Save as Markdown**.
2. The document opens rendered, beside it. Hold 2 seconds. Stop.

About 4 seconds.

## How

**ScreenToGif** — free, Windows, made for exactly this.

- Turn the keystroke overlay **on**, so `Alt+M` and `Alt+X` appear as they are
  pressed. Half the point is teaching the key.
- Zoom the editor up two or three steps (`Ctrl` and `+`) before recording. The
  page shrinks these to about 800px wide and unzoomed text turns to mush.
- Frame the editor only. No title bar, no sidebar, no taskbar, nothing of your
  own that you would not want strangers reading.
- 12 fps is plenty for this.
- Keep each one **under 3 MB**, or the page crawls on a slow connection.
- A dark theme gives a smaller, cleaner file than a light one.
